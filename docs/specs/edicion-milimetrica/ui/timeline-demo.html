Así debe verse el proceso cuando el agente edita un documento

Cada ícono gris es una herramienta que el modelo decidió usar, y la frase la escribe él mismo. Abre un paso para ver el comando, el resultado y la captura que revisó. En Word se ve el caso completo: la primera verificación falla y el agente corrige solo lo que faltaba.

Capturas, rutas, JSON y resúmenes salen del motor de referencia corriendo sobre archivos de prueba. Las líneas de «Revisión visual» son ejemplos de lo que devolvería el modelo de visión.

Cómo se lee cada paso

El ícono sale del tipo de herramienta (campo kind del evento); la frase, del campo description que llena el modelo. Solo se usan íconos que ya existen en components/trace-rail.tsx.
