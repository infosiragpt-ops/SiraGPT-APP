Uniqueness de `str_replace` (`old_str occurs more than once` / `not found`) **no** se trata como timeout ni como fallo de write-refuse.

`refuseWriteIfDestDirMissing` sin `existsSync` se salta (el helper vivo lo documenta). El loop **no** pasa `fs.existsSync` del host: las rutas de tools son sandbox-virtuales (`/workspace/outputs/…` en evals) y un existsSync del runner rechazaría `edit_file` legítimo. El fail-closed de dest-dir se mide inyectando `existsSync` (tests + applyWriteRefuseClosed). Rutas relativas (`src/a.js`) no coinciden con `/etc` `/proc` `/sys` `/dev` `/boot` `/root` `/mnt`.

`restoreLastSseIdOnResume` corre sobre una **copia** del cursorStore. El helper vivo muta `store.cursor`; clobber el store del caller rompía `rejectLastEventIdGoingBackwards` (3H64-D-001).
