# 3H57 — agent-loop robustness (engine-only)

WAVE 3H57 adds 40 pure helpers after 3H56 for the agent loop. No chat/code
layout, buttons, mobile chrome, or admin UI. Separate from #380 / #381 / #382.

DeepSeek V4 Flash/Pro only. No OpenRouter generate client.

## Helpers

- Loop: refuse finish while tool results pending; cut after the same observation
  hash thrice; stop if the final is still empty after max repairs; refuse
  nameless tool calls.
- Tool schema / retry / repair: unwrap double-encoded JSON once; coerce ISO
  dates or refuse; 503 Retry-After backoff; refuse type mismatch after coerce;
  strip C0 from tool names.
- Subagent: inherit max output tokens; cut at zero remaining tokens; refuse if
  the parent fence is lost; cap nested fanout.
- Compact / pgvector: keep system + pinned facts; reject dim ≤ 0; pin facts
  above a score threshold; drop duplicate memory hits by id.
- Checkpoint: refuse checksum mismatch; keep tombstones + last N; refuse
  rollback to a seq newer than head.
- Exact diffs: require `diff --git` + `index`; SHA-256 read-after-write; refuse
  minus lines on a new file; hunk header counts must match the body.
- Sandbox: stderr byte cap; open-files cap; cwd must stay under workspace.
- SSE: skip already-acked ids on resume; reject session mismatch; drop a
  partial frame on cancel; skip heartbeat if the client is gone.
- Queue: reject enqueue over depth; promote when the deadline is close.
- Credits: no charge on prompt-only cancel; settle once per requestId; ignore
  negative completion tokens.
- Errors / latency: ECONNREFUSED → unavailable; never retry 403; TTFB budget
  hint; scripted p95 sample.

## Wiring

Fail-open re-export from `engine-adapter.js` (`try/catch require`). Snapshot
`wave` is `3H57`; 3H46 flags stay true.

Live hooks are additive only in `loop.js`, `sse-writer.js`,
`agent-gateway/queue.js`, `engine-gateway.js`, and `local-sandbox.js`.
Production durability stacks (fence, stall, F7, SSE backpressure/Nagle) are
not rewritten.
