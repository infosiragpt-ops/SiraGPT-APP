# Wave 3H56 — agent-loop robustness (engine-only)

Engine helpers that close remaining holes after 3H55 without touching chat/code
layout, buttons, mobile chrome, or admin UI. DeepSeek V4 Flash/Pro only — no
OpenRouter generate client. Continuity mounts from PR #380 (Activos passthrough,
`tryDocEngineAfterSelection`, SDIE, ACS, DeepSeek lock) are not modified.

Module: `backend/src/services/agent-runner/engine-3h56.js` (re-exported from
`engine-adapter.js`). Wired fail-open into `loop.js`, `sse-writer.js`,
`agent-gateway/queue.js`, `engine-gateway.js`, and `local-sandbox.js`. Production
durability stacks in `loop.js` / `sse-writer.js` are not rewritten.

## Helpers (39)

### Agent multi-step loop
1. `refuseFinishWhileParallelToolsOpen` — refuse final while parallel tools are still open
2. `cutLoopIfSameToolCallIdReused` — same `tool_call_id` twice in one turn cuts the loop
3. `stopIfMaxStepsWithPartialFinal` — at the step cap, deliver partial text
4. `refuseEmptyAssistantWithOpenTools` — empty assistant + open tools is invalid

### Strict tool schemas + retry/repair
5. `rejectUndefinedRequiredToolArgs` — required keys must not be `undefined`
6. `repairJsonSingleQuotedValuesOnce` — `{'foo':1}` → `{"foo":1}` once
7. `coerceEnumArgOrRefuse` — case-insensitive enum coerce, else refuse
8. `backoffOn429RetryAfterHeader` — 429 respects `Retry-After`
9. `stripUnknownArgsWhenAdditionalPropertiesFalse` — drop extra keys
10. `refuseToolIfRequiredMissingAfterRepair` — still-missing required after repair

### Subagent budget
11. `inheritSubagentTokenBudget` — child tokens ≤ parent remainder
12. `cutSubagentIfNoProgressTwoSteps` — identical observation hash twice
13. `shareParentAbortDeadlineMs` — child wall clock ≤ parent deadline
14. `capSiblingSubagentsPerParent` — default 2 siblings per parent

### Compact / pin / pgvector
15. `compactKeepPinnedAndLastUserPair` — pins + last user/assistant pair
16. `rejectPgvectorNaNOrInfComponents` — refuse NaN/Inf embeddings
17. `pinFactsWhenFlagTrue` — keep `pin:true` facts
18. `dropToolBodiesOlderThanNTurns` — drop stale tool_result bodies

### Checkpoint rollback
19. `refuseRollbackIfSeqNotMonotonic` — cannot roll forward past current seq
20. `checkpointKeepLastNPlusPinned` — last N + pinned checkpoints
21. `refuseRollbackAcrossSessionBoundary` — checkpoint session must match

### Exact diffs + read-after-write
22. `refuseDiffMissingGitHeaders` — require `---` / `+++`
23. `verifyReadAfterWriteLineCount` — line count must match after write
24. `refuseBinaryPatchOnTextFile` — no GIT binary patch on text paths
25. `requireHunkContextLinesMatch` — context lines must equal source

### Sandbox limits
26. `capSandboxStdoutBytesPerCommand` — per-command stdout cap
27. `refuseSandboxRssOverCap` — RSS over 256 MB refused
28. `requireSandboxTmpdirUnderPrefix` — tmpdir must stay under prefix

### SSE resume / cancel
29. `resumeReplayMustBeIdempotent` — replay skip is deterministic
30. `rejectResumeIfCursorAheadOfHead` — Last-Event-ID cannot pass head
31. `dropBufferedTokensOnCancelOnce` — drop buffered tokens once on cancel
32. `heartbeatJitterWithinWindow` — heartbeat jitter must stay in range

### Session queue
33. `rejectEnqueueIfSessionLockedByOther` — foreign lock owner rejected
34. `boostStarvedQueueAfterWaitMs` — starve boost after 20s

### Credit accounting
35. `neverChargeIfNoCompletionAndNoErrorUsage` — no phantom tokens
36. `settleHoldOnceOnTerminalState` — hold settles once

### Classified errors + latency
37. `classifyDnsEnotfoundAsUnavailable` — ENOTFOUND / EAI_AGAIN retryable
38. `neverRetry401Unauthorized` — 401 never retries
39. `latencyHintWhenStepOverBudget` — step slower than 15s
