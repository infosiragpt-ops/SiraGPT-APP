# 3H58 — agent-loop robustness (engine-only)

WAVE 3H58 adds 40 pure helpers after 3H57 for the agent loop. No chat/code
layout, buttons, mobile chrome, or admin UI. Separate from #380 / #381 /
#382 / #383 / #384.

DeepSeek V4 Flash/Pro only. No OpenRouter generate client.

## Helpers

- Loop: refuse finish while plan todos are open; cut after the same assistant
  content hash twice; stop after max empty assistant turns; refuse tool calls
  missing both id and name.
- Tool schema / retry / repair: unwrap `+{...}` JSON once; coerce emails or
  refuse; 504 gateway-timeout backoff; refuse unknown enum after repair; strip
  zero-width characters from tool names.
- Subagent: inherit max steps; cut if the parent deadline passed; refuse if
  parent tokens are exhausted; cap stdout at 16 KiB.
- Compact / pgvector: drop orphan tool_results; reject non-finite / zero
  embedding norms; pin facts by access count; drop hits with an empty vector.
- Checkpoint: refuse byte-length mismatch; keep last failed attempts; refuse
  rollback when unrelated dirty paths remain.
- Exact diffs: require `---` / `+++` headers; SHA-256 prefix read-after-write;
  refuse rename without a delete; hunk start line must exist.
- Sandbox: combined stdout+stderr cap; refuse host-path env leaks; refuse
  uid 0.
- SSE: skip ids outside the ring window; reject writer-generation mismatch;
  drop heartbeat if seq is unchanged; stamp server now-ms.
- Queue: reject duplicate requestId; demote after a hard wait cap.
- Credits: no charge if the stream never opened and the turn cancelled;
  settle only after the done event; ignore prompt tokens over the hard cap.
- Errors / latency: ETIMEDOUT → timeout; never retry 409; p99 step budget
  hint; scripted p50 sample.

## Wiring

Fail-open re-export from `engine-adapter.js` (`try/catch require`). Snapshot
`wave` is `3H58`; 3H46 flags stay true.

Live hooks are additive only in `loop.js`, `sse-writer.js`,
`agent-gateway/queue.js`, `engine-gateway.js`, and `local-sandbox.js`.
Production durability stacks (fence, stall, F7, SSE backpressure/Nagle) are
not rewritten. `/code` chrome and Arrancando-related UI files are not
touched.
