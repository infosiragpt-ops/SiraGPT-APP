# Traducción profesional

Traduce con fidelidad al sentido, naturalidad en el idioma de destino y coherencia
terminológica, como lo haría un traductor profesional que además revisa su trabajo.

## Cuándo usar
- Traducir documentos, contratos, manuales, artículos, páginas web, interfaces o correos.
- Revisar o corregir una traducción existente.
- Localizar contenido para un país concreto (moneda, fechas, referencias culturales).

## Procedimiento
1. **Define el encargo:** idioma y variante de destino (ej. español de México, inglés
   británico), público, finalidad (informativa, legal, publicitaria, técnica), registro
   y si hay glosario o guía de estilo. Si no se indica la variante, pregúntala o elige
   una neutra y dilo.
2. **Lee el texto completo antes de traducir** para entender el tema, el tono y los
   términos recurrentes.
3. **Construye un glosario** de términos clave (técnicos, nombres de producto, cargos,
   siglas) y úsalo de forma consistente. Los nombres propios, marcas y títulos oficiales
   no se traducen salvo que exista traducción oficial.
4. **Traduce el sentido, no palabra por palabra:** reestructura frases cuando la
   sintaxis del idioma de destino lo pida; adapta modismos por equivalentes, no por
   calcos.
5. **Cuida los falsos amigos** (EN→ES): *actually* ≠ actualmente, *eventually* ≠
   eventualmente, *library* ≠ librería, *sensible* ≠ sensible, *embarrassed* ≠
   embarazada, *assist* ≠ asistir (en el sentido de presenciar), *application* puede
   ser solicitud.
6. **Adapta convenciones:** formato de fecha, separadores decimales, unidades, moneda
   (sin convertir importes salvo petición), comillas («» o “” según la norma elegida),
   mayúsculas (en español no van en meses, días ni gentilicios).
7. **Textos legales o técnicos:** máxima fidelidad; no simplifiques ni omitas cláusulas.
   Si un término no tiene equivalente exacto en el sistema de destino, conserva el
   original entre paréntesis o añade nota del traductor.
8. **Preserva el formato:** encabezados, listas, tablas, negritas, enlaces, variables
   de interfaz (`{nombre}`, `%s`) y etiquetas HTML intactas.
9. **Revisa** en una segunda pasada: omisiones, cifras y nombres copiados exactamente,
   concordancias, coherencia del glosario y naturalidad leyendo solo el texto traducido.

## Formato de salida
```
<Traducción, con el mismo formato que el original>

---
**Notas de traducción** (solo si hay algo relevante)
- Término → decisión tomada y motivo.
- Ambigüedades del original que conviene confirmar.
**Glosario** (en textos largos o técnicos)
| Original | Traducción |
```

## Criterios de calidad
- [ ] No hay omisiones ni añadidos respecto al original.
- [ ] Cifras, fechas, nombres y enlaces coinciden exactamente.
- [ ] La terminología es consistente en todo el texto.
- [ ] Se respeta la variante y el registro pedidos.
- [ ] El texto se lee como escrito originalmente en el idioma de destino.
- [ ] Variables, etiquetas y formato se conservan.

## Errores a evitar
- Traducción literal que produce frases forzadas.
- Traducir nombres de marcas, productos o instituciones sin traducción oficial.
- "Corregir" el contenido del original en silencio: si hay un error, señálalo en notas.
- Mezclar variantes (vosotros y ustedes en el mismo texto).
- Presentar una traducción como jurada o certificada: eso requiere un profesional habilitado.
