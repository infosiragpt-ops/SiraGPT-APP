# Correo profesional

Escribe correos que se entienden en una lectura y consiguen una respuesta: asunto
informativo, propósito en la primera línea, petición concreta y cierre claro.

## Cuándo usar
- Solicitudes, seguimientos, presentaciones, reclamos, respuestas a clientes, correos
  a superiores o a desconocidos.
- Mejorar un borrador del usuario (tono, claridad, extensión).
- Responder un correo recibido que el usuario pega.

## Procedimiento
1. **Define propósito y destinatario:** qué debe hacer o saber el destinatario después
   de leer, relación con el remitente (cliente, jefe, proveedor, desconocido) y
   contexto previo. Si falta algo esencial (nombre, fecha, monto), usa un marcador
   `[nombre]` en lugar de inventarlo.
2. **Elige el registro:** formal (usted) para desconocidos, autoridades y clientes
   nuevos; cordial (tú o usted según la costumbre del usuario) para relaciones
   establecidas. Respeta el tratamiento que el usuario ya use con esa persona.
3. **Asunto:** 4–9 palabras que resuman el contenido y, si aplica, la acción o fecha
   ("Aprobación de presupuesto Q4 — respuesta antes del 15/10").
4. **Primera línea:** el motivo del correo. Nada de "Espero que se encuentre bien" como
   único contenido del primer párrafo (se puede usar, pero breve).
5. **Cuerpo:** contexto mínimo necesario, datos concretos (fechas, cifras, enlaces,
   adjuntos mencionados), en párrafos de 2–3 líneas o viñetas si hay varios elementos.
6. **Petición explícita:** qué, de quién y para cuándo. Una sola petición principal.
7. **Cierre:** agradecimiento breve o siguiente paso, despedida acorde al registro y firma.
8. **Revisa:** longitud (idealmente menos de 150 palabras), tono (sin reproches ni
   exceso de disculpas), ortografía, nombres y adjuntos mencionados.
9. **Ofrece variantes** solo si el tono es delicado (p. ej. versión más firme y más suave).

## Formato de salida
```
**Asunto:** <asunto>

<Saludo>,

<Motivo en 1–2 frases.>

<Contexto y datos necesarios.>

<Petición concreta con plazo.>

<Cierre>,
<Firma>
```
Tras el correo, en una línea: marcadores que el usuario debe completar y, si se mejoró
un borrador, los 2–3 cambios principales.

## Criterios de calidad
- [ ] El asunto permite entender el correo sin abrirlo.
- [ ] El propósito aparece en las dos primeras líneas.
- [ ] Hay una petición clara con plazo, o se indica que es solo informativo.
- [ ] Tono coherente con la relación y el objetivo.
- [ ] Sin datos inventados; los faltantes van como marcadores.
- [ ] Menciona los adjuntos si los hay.

## Errores a evitar
- Párrafos largos o varias peticiones mezcladas.
- Excesivas disculpas o fórmulas vacías.
- Tono pasivo-agresivo en seguimientos ("Según mi correo anterior…").
- Mayúsculas, signos de exclamación múltiples o emojis en correos formales.
- Inventar fechas, acuerdos previos o nombres.
